Ember Duel — an original turn-based battle card game. You duel Mara across a felt table: both start at 30 life, draw cards, spend ember to strike, guard, or mend, and chain same-suit cards for a Harmony discount. First to 0 life loses. Played with mouse and keyboard, offline, from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and click START DUEL. Or serve `game/` with any static server and open `game/index.html`.
